## 💡 Sobre

Landing page de uma escola de tecnologia fictícia, construída a partir de um layout no Figma (`assets/aprenser.fig`), com foco em HTML semântico e CSS puro.

## ✨ Seções

- Hero com chamada "O saber é o que transforma nosso SER"
- Principais cursos: Design para Web, Front-end e Back-end
- Nossa escola
- Contatos

## 🛠️ Tecnologias

HTML5 · CSS3 (normalize + reset) · Figma

## 🚀 Como rodar

Projeto estático, sem build:

```bash
git clone https://github.com/KevinLopes23/Aprenser.git
cd Aprenser
```

Abra o `index.html` no navegador (ou use uma extensão como Live Server).
